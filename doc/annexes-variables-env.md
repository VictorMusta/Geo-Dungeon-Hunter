# Variables d'environnement

[< Retour au sommaire](README.md)

---

| Variable | Description | Defaut |
|----------|-------------|--------|
| `API_VERSION` | Version affichee par `/version` | `"1.0.0"` |
| `MODE` | Mode d'execution (`DEVELOP` / vide) | -- |
| `DB_HOST` | URI de connexion MongoDB Atlas | -- |
| `API_PORT` | Port d'ecoute | `":8080"` |
| `ALLOW_ORIGIN` | CORS allowed origins | `"*"` |
| `LOG_FORMAT` | Format des logs (`HUMAN` / `JSON`) | `HUMAN` |
